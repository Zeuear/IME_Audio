把听写结果写进 Google 文档

装好扩展后，听写的文字会直接写进绑定的 Google 文档标签页，不影响你当前正在使用的窗口。

一、安装扩展（只需一次）

  1. 在 Chrome 地址栏输入 chrome://extensions 并回车。
  2. 打开页面右上角的开发者模式。
  3. 点左上角加载已解压的扩展程序，选择 ImeAudio 刚才打开的 google-docs 文件夹（也就是本说明所在的文件夹）。文件夹路径已复制到剪贴板，可以直接粘贴到选择框的地址栏。
  4. 扩展列表里出现 ImeAudio · Google 文档输出 即安装成功。建议点工具栏的拼图图标，把它固定到工具栏。
请不要移动或删除这个文件夹，Chrome 每次启动都从这里加载扩展。

二、配对并绑定文档

  1. 在 ImeAudio 横条上点右键，勾选输出到 Google 文档，再点复制 Google 文档配对码。
  2. 打开要写入的 Google 文档标签页，点工具栏里的 ImeAudio 扩展图标。
  3. 在弹窗里粘贴配对码，点保存并绑定当前标签页。配对码只需粘贴一次。
  4. 图标出现绿色 ON 角标即已绑定。之后听写的文字写进这个文档，不再输入到前台窗口。

三、日常使用

  1. 换一个文档：打开那个标签页，点扩展图标，再点绑定当前标签页。
  2. 停止写入文档：点扩展图标里的解除绑定，或在 ImeAudio 右键菜单取消勾选输出到 Google 文档。

常见问题

  1. Chrome 顶部出现"正在调试此浏览器"横幅。这是扩展写入文档所用接口的固有提示，绑定期间一直显示。请不要点"取消"，否则绑定会断开。
  2. 图标角标显示 KEY。还没有保存配对码，按第二步操作。
  3. 图标角标显示 ERR。当前标签页无法绑定（例如 chrome:// 页面，或已被别的调试工具占用）。请换到 Google 文档标签页再试。
  4. 已绑定但没有文字写入。确认 ImeAudio 正在运行，并且右键菜单里勾选了输出到 Google 文档。
  5. ImeAudio 升级之后。在 ImeAudio 右键菜单再点一次安装 Google 文档扩展，然后在 chrome://extensions 里点该扩展的刷新按钮。

Send dictation to Google Docs

With the extension installed, dictated text goes straight into the bound Google Docs tab without touching the window you are working in.

1. Install the extension (once)

  1. Type chrome://extensions in Chrome's address bar and press Enter.
  2. Turn on Developer mode at the top right.
  3. Click Load unpacked and choose the google-docs folder ImeAudio just opened (the folder this guide is in). Its path is on your clipboard, so you can paste it into the folder picker.
  4. ImeAudio · Google 文档输出 appears in the list. Pin it to the toolbar from the puzzle-piece menu.
Do not move or delete this folder. Chrome loads the extension from it on every start.

2. Pair and bind a document

  1. Right-click the ImeAudio bar, tick Output to Google Docs, then click Copy Google Docs Pairing Code.
  2. Open the Google Docs tab you want to write into and click the ImeAudio extension icon.
  3. Paste the pairing code and click the save-and-bind button. The code is only needed once.
  4. A green ON badge means the tab is bound. Dictation now goes to that document.

Troubleshooting

  1. "…is debugging this browser" banner. It is shown by Chrome for as long as a tab is bound. Do not click Cancel, or the binding is dropped.
  2. KEY badge. No pairing code saved yet. Follow step 2.
  3. ERR badge. The current tab cannot be bound. Switch to a Google Docs tab and try again.
  4. After updating ImeAudio. Click Install Google Docs Extension in the ImeAudio menu again, then press the reload button of the extension in chrome://extensions.
