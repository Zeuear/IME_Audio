# ImeAudio Google 文档输出扩展

1. Chrome 打开 `chrome://extensions`，开启"开发者模式"，"加载已解压的扩展程序"选本目录。
2. ImeAudio 横条右键菜单点"复制 Google 文档配对码"，在扩展的选项页粘贴并保存（只需一次）。
3. 菜单勾选"输出到 Google 文档"。
4. 打开文档标签页，点扩展图标（角标 ON 即已绑定；再点解除）。
5. 之后听写的文字写进该文档，不再注入当前前台窗口。

绑定期间 Chrome 会显示"正在调试此浏览器"横幅，这是调试器协议的固有提示，不要点"取消"。
扩展 ID 由 manifest 的 `key` 固定，程序只接受这个 ID，并校验配对码。
