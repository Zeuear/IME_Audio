ImeAudio 是一款高性能、AI 驱动的实时语音转录与文本润色工具。旨在为用户提供无缝的工作流体验，通过结合顶尖的本地与云端语音识别引擎，将您的语音瞬间转化为精准、优雅的文字。

## 🌟 核心功能

### 🎙️ 智能语音转录
* **多引擎支持：** 支持本地 **Sherpa** 引擎，或使用 **Gemini**、**Groq**、**Gladia** 等高性能云端引擎。
* **智能语音检测 (VAD)：** 自动识别语音片段，实现高效、精准的录音与处理。
* **实时频谱可视化：** 基于 FFT 的精美频谱与波形动画，实时反馈音频状态。

### ✨ AI 文本精炼
* **智能润色：** 利用大语言模型 (LLM) 自动修复语法、调整语气或重新编排文本。
* **高度自定义：** 支持自定义 Prompt、专业 AI 词库以及文本替换规则。
* **术语管理：** 内置 `Terms Library`（术语库），确保专业词汇转录的准确性。

### 🛠️ 无缝工作流
* **全局热键：** 支持通过快捷键随时随地触发转录，不中断现有操作。
* **现代化 UI/UX：** 基于 Qt/QML 构建，拥有类似 macOS 的精致界面、平滑动画与现代审美。
* **后台运行：** 轻量级系统托盘集成，实现静默高效工作。
* **自动更新：** 内置自动更新机制，始终保持功能最新。

## ⚙️ 配置说明
应用采用 `AppConfig` 配置系统，允许您自定义：
* **引擎选择：** 本地引擎 vs 云端引擎。
* **API 凭据：** Gemini, OpenAI 等。
* **UI 主题：** 明亮、黑暗、灰色或跟随系统。
* **语音规则：** 自定义词库与润色风格。

## 🛠 技术栈
* **框架:** Qt 6 (C++/QML)
* **音频引擎:** miniaudio / QAudioSource
* **数字信号处理 (DSP):** kiss_fft
* **AI 引擎:** Sherpa (本地), Gemini, Groq, OpenAI


## 🗺️ 未来方向与计划 (Roadmap)

### ✨ AI 能力增强
- **多轮上下文润色：** 让 AI 记住前后文语境，而不仅是单次转录片段，提升长语音场景下的连贯性。
- **说话人分离 (Speaker Diarization)：** 支持多人对话场景，自动区分不同说话人并分段标注。
- **场景化 Prompt 模板：** 内置「会议纪要」「邮件草拟」「代码注释」「社交媒体文案」等预设润色模板，一键切换风格。
- **本地 LLM 支持：** 接入 Ollama / llama.cpp 等本地大模型，实现完全离线的转录+润色闭环，保护隐私。
- **实时流式润色：** 在语音输入过程中即时展示润色结果，而非等待完整片段结束后处理。

### 🔌 引擎与平台接入
- **更多云端 ASR 引擎：** 除 Gemini、Groq、Gladia 外，计划支持 AssemblyAI、Deepgram、阿里云/腾讯云语音识别等，方便国内外用户选择。
- **更多 AI 润色后端：** 支持 Claude、DeepSeek、通义千问等模型接入，用户可自由切换润色引擎。
- **本地引擎优化：** 持续跟进 Sherpa-onnx 模型更新，支持更多语言与方言识别。

### 💻 平台与生态
- **macOS / Linux 正式版：** 完成跨平台适配，提供原生安装包与系统集成（如 macOS 菜单栏、Linux 托盘）。
- **移动端探索：** 评估 Android/iOS 端轻量转录工具的可行性，与桌面端配置同步。
- **插件化架构：** 开放术语库、Prompt 模板、引擎适配器的插件接口，方便社区扩展。

### 🛠️ 工作流与体验
- **多语言界面：** 完善 UI 多语言支持（当前中英文基础上增加日语、韩语等）。
- **快捷指令市场：** 允许用户分享/导入自定义热键+Prompt 组合，形成社区模板库。
- **历史记录与搜索：** 增加转录历史的本地存储、全文搜索与导出（Markdown/TXT/SRT）功能。
- **云同步（可选）：** 支持配置、术语库、Prompt 模板的跨设备同步（端到端加密，用户可控）。

### 📊 质量与性能
- **转录准确率评测体系：** 建立标准测试集，持续跟踪不同引擎/模型的准确率与延迟表现。
- **资源占用优化：** 降低本地引擎的 CPU/内存占用，提升低配设备上的运行体验。

> 💡 以上计划会根据社区反馈和实际开发进度动态调整，欢迎在 Issues 中提出你的想法！
